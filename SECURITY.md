# Security reports

Please do not publish credentials, private church content, active enrollment codes, or exploitable vulnerability details in a public issue.

Use this repository's **Security → Report a vulnerability** option if available. Otherwise contact an organization owner privately through their published contact channel to arrange a confidential report before sharing sensitive details.

Include the affected application/version, relevant source paths, reproduction steps, impact and a minimal example with synthetic data. Never include production passwords, tokens or signing keys.

Source publication and automated secret checks are not a guarantee that an application has no vulnerabilities. A comprehensive security audit has not been completed. Release signing keys and deployment secrets are managed outside this repository.
