# Stați preview 34

Repairs desktop startup after an update or profile sign-in. The installed computer opens its local workspace and Who are you prompt using its saved pairing; it never asks for the mobile website passcode. New installations use Connect this computer onboarding. Desktop web browsers show passkey sign-in while phones and tablets retain the invitation/computer-code flow.

Retrying pairing reuses a confirmed existing connection or the same unfinished QR connection after a restart. Simultaneous retries share one request. Temporary network/authentication errors cannot replace the saved computer credential. Only a confirmed expired/revoked pairing or an explicit removal permits a replacement. Protected credentials use staged encrypted writes; the prior encrypted credential is preserved when an expired connection is replaced. Pairing responses are checked using the real flat API response shape.

Removes Stați’s fixed-window attempt lockouts, including old counters left by previous versions. Incorrect PINs and codes still fail; a correct PIN or valid code remains usable after repeated mistakes. Passkeys, current operator proof, station approval, membership permissions, file limits and single-use challenges remain required.

Uses the supplied Stați logo for website favicons and iPhone Home Screen icons, with explicit iOS dimensions and refreshed icon URLs. An existing iOS shortcut may need to be removed and added again to refresh its cached icon. The public What’s new history includes the verified Preview 33 release.

No account, computer, song or received file is deleted by this update. Windows production signing, physical Windows 11/iPhone checks and ProPresenter 7.11 acceptance remain outstanding. This is an unsigned Windows preview.
