# Stați Windows preview 30

“Skip for now” replaces the visible window fallback from five minutes before a service until the service ends. Skipping hides the prompt without signing anyone in; reopening asks who is using the computer. Fullscreen stays off during service and the protected post-service period, and the profile card remains white over the blurred background.

Prepare slides shows the selected service for newly saved songs. Creating services queues local ProPresenter playlists, with saved Lyrics presentations added by native identity rather than title. Services expose waiting/synced states, preserve unsaved edits, and reject stale saves. Administrator settings control the local API port and optional day/week cleanup. ProPresenter’s documented API cannot delete playlists; cleanup can remove the local service and only Stați-added entries, keeping Lyrics and manual entries.

Amen/Amin is slightly larger, remains italic and nonbold, and song search shows matching lyrics from later slides.

Windows installers keep desktop shortcut creation disabled. Legacy Stați desktop shortcuts are moved quietly to private recovery storage once, and the new uninstaller avoids the global desktop-icon refresh during upgrades. The first update from an older installer still runs its previous uninstaller and can flicker once. Normal Exit and uninstall remain available.

This is an unsigned Windows preview. Local tests and isolated UI/API checks do not replace church-PC verification of startup blur, ProPresenter 7.11 and update behavior.
