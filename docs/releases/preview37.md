## Church workflows and protected song updates

- Prepare can review likely guitar chords before removing them, apply only the selected changes, and undo the operation exactly. Lyrics remain editable before export.
- Library can create a named group/person copy with a new presentation identity, preserving the generic song. Group labels and filtering are shared with the website. Generic duplicate detection keeps group-specific arrangements separate.
- Incoming PC downloads reserve 2 GiB plus metadata headroom, including concurrent streams and recovery fallback copies. Low-space failures leave delivery retryable. Existing PC files are not automatically deleted; phone uploads can still queue online while the PC is low on space.
- Service leaders explicitly claim and finalize their running order. Approved worship members can explicitly take over for an absent leader. Operator acknowledgement is separate and tied to the exact saved revision.
- Shared group files keep PDF/JPG/PNG/WebP chord sheets and lyric references available to approved ministry users across devices. Files have group labels, upload progress/cancel, authenticated viewing/downloads, and deliberate uploader/admin removal. Active shared files have no automatic expiry.
- Feedback & tasks has New, In progress and Complete, urgent flags, details, replies and phone-friendly status controls. Permissions and revision checks protect updates.
- Explicitly linked existing PowerPoint/ProPresenter pairs can synchronize saved lyric edits in either direction after native opt-in and verified backups. Automatic checks run while an authorized Windows editing profile is unlocked. Missing endpoints are skipped with an operator warning; concurrent edits, unsupported layouts and sharing violations stop for review. Text updates preserve presentation identities, media, geometry and supported formatting. Save open work before enabling sync; unsaved edits inside another application are outside file monitoring.
