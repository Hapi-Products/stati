# Stați preview 35

Fixes song-library sharing and visibility. The website homepage opens Library for accounts with song access; Computers remains available for sending files. Saved computers that arrive after the Songs page opens are selected correctly. Published lyrics stay readable when the receiving PC is offline and outside service hours, subject to current account roles and station approval. The website shows the last successful sync, explains when no library has been shared yet, and refreshes while Songs is visible without touching an unsaved service draft. Phones still need an internet connection to read the shared catalog.

The Windows app schedules sharing after choosing Lyrics and after successful conversions, inserts, exports and edits, including when no active service is selected. The library offers a compact Sync phones control with protected sync status. Background scans use the saved Lyrics folder and never open a folder picker.

A scan in which every file is unreadable cannot replace the last shared library with an empty one. The server enforces this for older clients as well. A verified empty folder may still publish an explicitly empty catalog; partially readable scans include their existing incomplete-results warning.

PROJECTION had no previously published catalog during investigation. An updated PC must come online once and share its Lyrics library before phones can display those songs while the PC is off. This update does not invent songs or merge unrelated computer records.

This is an unsigned Windows preview. Physical Windows/iPhone and ProPresenter 7.11 checks remain pending. No new AI or paid provider is used.
