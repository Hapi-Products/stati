# Stați Windows preview 29

Fullscreen identity prompts stay off during services, including Windows startup, unlock and Switch User. If a full-screen prompt is already open before a service starts, it switches to a small window at the service start time. The existing two-hour post-service window remains protected.

Outside service and that post-service period, the full-screen “Who are you?” prompt uses the blurred primary desktop. The profile card stays white with dark text, and the small Windows identity window also uses native blur when available. In-app and off settings remain available. This is an unsigned Windows preview; physical Windows 11 display and startup verification remains open.
