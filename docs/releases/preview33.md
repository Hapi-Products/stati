# Stați preview 33

The identity prompt now uses a dark blurred backdrop with a white account card. Skip for now hides the prompt reliably even when Windows finishes leaving fullscreen later; it remains available only in the configured pre-service and service window. Cancelling a PIN or phone choice before entering the workspace clears that choice.

A public What’s new page at /changelog is available without signing in, including from older browser/app versions. It lists verified published releases. The desktop sidebar links to the hosted page.

Additive ministry roles include worship leader, worship member, pastor and choir director. Worship leaders can approve worship members and assign worship roles to other eligible accounts. Administrators control administrator, pastor and choir-director roles. Named ministry profiles use their phone passkey on the PC; selecting a name alone grants no ministry privilege. Pastors can view songs and send files, with song and service editing rejected by the server and native IPC.

Approved ministry users can browse a computer’s published song catalog and plan services on their phones or the PC. The PC publishes complete, bounded catalog snapshots; a partial upload keeps the previous catalog. Shared service edits use current revisions and permission checks to reject conflicting or revoked writes. Local service source copies and known ProPresenter playlist bindings are preserved during migration. Conversion, OCR, filesystem writes and ProPresenter work run on the PC.

The song library has live search and list/grid first-slide previews. Services use numbered song cards, hold/drag reordering, live search and automatic saving with a manual Save fallback. Failed saves keep the draft open and prevent switching computers. The slides window uses a compact left workspace rail and the native Windows title bar.

Existing library lyric edits save automatically into the same file path, retaining its title and presentation identity. Private recovery copies and expected-content hashes protect against conflicting edits. The public ProPresenter API has no lyric-edit endpoint; immediate refresh in ProPresenter 7.11 still needs verification on the receiving PC. Stați does not delete/reimport the presentation to force a refresh.

New service playlists use date/time names such as “Oct 27 - 9:00 PM”. Known playlist bindings remain stable. Ordered updates preserve manually added playlist entries and handle repeated songs. Definitively rejected create requests can retry; ambiguous network results retain checkpoints to avoid duplicate playlists.

Windows packaging removes duplicate build inputs and macOS-only native payloads while retaining the bundled OCR/PDF runtime, languages, fonts, codecs and license notices. Actual installer savings and packaged runtime results are recorded during release checks.

This batch needs additive database migrations 0011–0013 and a coordinated website/server update. Automatic cleanup for shared services remains disabled while its cloud implementation is prepared; current services and playlists are kept. Existing local retention preferences are preserved. Native ProPresenter playlist deletion remains manual.

Unsigned Windows preview. Local automated and browser checks do not replace physical Windows 11, iPhone, blur, touch, notifications or ProPresenter 7.11 acceptance. Windows production signing and independently verified Android signing recovery remain release gates. No new AI or paid provider is used.
