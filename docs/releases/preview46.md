This unsigned Windows preview adds **Choose library folder** to the song library. Select the existing Lyrics folder, or choose a synced parent folder that contains Lyrics. Stați reads that folder and shares its supported song catalog with approved devices. The previous library files are kept in their original location.

A Google Drive for desktop folder works as a local source when its files are available on the computer. After external edits finish syncing to the computer, use **Share library** to refresh Browse on the iPad. The Windows installer requires a device check.
