# Stați Windows preview 28

The “Who are you?” prompt now opens full screen when Windows starts or unlocks, including when a service has already started. The previous service rule incorrectly kept this startup prompt in a small window, as shown in the reported Tuesday evening photo.

The primary desktop uses the local blurred snapshot already supported by Stați. Selecting a profile restores the normal workspace. Switch User still uses a small window during service and the two hours afterward; the in-app and off settings remain available. If native Acrylic is unavailable, that alone no longer cancels fullscreen presentation.

This is an unsigned Windows preview. Local policy, native-window adapter and interface checks do not replace checking startup, blur and display behavior on the church Windows 11 PC. No ProPresenter playlist or automatic deletion changes are included in this priority release.
