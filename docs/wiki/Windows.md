# Stați for Windows

**Updated on** November 11, 2026 · **Updated by** Codex for Stați

Use Windows for the church presentation computer. This is where you receive submissions, manage the shared library, and use the desktop presentation tools.

## Get started

1. Check [Stați releases](https://github.com/markusciani/stati-releases/releases) for the Windows installer your church uses. The release notes identify preview builds.
2. Open Stați. For a new installation, follow the pairing prompt. If the computer is already paired, choose your profile and complete its sign-in.
3. Use **Queue** to review incoming files. Open a submission before choosing how to save or reject it.
4. In **Prepare Slides**, select the source files and the appropriate destination. Check the generated slides and slide order in the presentation app before service.

## Plan a service

Open **Services**, choose a date and time, add songs to the running order, and save. To confirm a change, reopen the service and check the order. Use the archive action to remove a completed service from the active list while keeping its plan available for later reference.

If saving takes a long time, keep your editor open and look for the save status. A new song may need to finish syncing to the station catalog before the service can use it. If an archive fails, refresh the list and check the result before retrying.

## ProPresenter

Use the network API on the same presentation computer as ProPresenter. In Stați’s playlist settings, match the configured port and use the connection check before trusting playlist sync. Open ProPresenter to confirm the expected playlist and its actual order. A verified connection confirms access to the API. Check the real running order separately.
