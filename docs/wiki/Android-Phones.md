# Stați for Android phones

**Updated on** November 11, 2026 · **Updated by** Codex for Stați

Stați on Android uses the secure Stați web experience in a Trusted Web Activity. The Android test APK targets Android 9 or later. Check [Stați releases](https://github.com/markusciani/stati-releases/releases) for the build your church distributes.

## Start using Stați

1. Open Stați or visit the [Stați website](https://stati.ciani01.org).
2. Sign in with the passkey for your account. For first-time setup, follow the church’s current invite.
3. Use your phone’s camera to scan the receiver QR when the church computer shows it. Confirm the destination before submitting.
4. Choose the file and wait for its result. Reopen the receiver page if the original code expired.

If a development APK opens with a browser address bar, the browser may be showing that its test certificate is separate from the site’s verified app identity. Use the official site or ask your maintainer for the current build.

Desktop PowerPoint conversion, OCR, and ProPresenter controls run on the presentation computer.
