# Troubleshooting

**Updated on** November 11, 2026 · **Updated by** Codex for Stați

| What you see | What to check |
| --- | --- |
| A QR code expired | Generate a new code on the computer and check that it was created for the action you want. |
| A connected computer appears offline | Confirm the app is open on the computer, the computer has a network connection, and you selected the correct station. |
| The service keeps loading | Check the station connection and refresh. Keep an unsaved edit open until you know its save status. |
| A new song is missing | Confirm it was saved to the station catalog. Search by a lyric fragment if the title matches several songs. |
| An upload is still queued | Check the receipt and ask the computer operator to review its queue. |
| A passkey prompt loops | Check that the account and computer match. Use the sign-in options shown by that build and record the exact error if it repeats. |
| You cannot see the Worship settings | Check that you are using an iPad with the correct preview build, then look under **Settings → Apps → Stați**. |

When reporting an issue, include your device, OS version, Stați build, the screen, and the exact error. Keep invite codes, passkeys, and personal account details out of public reports.

## Report a problem on iPhone or iPad

1. Open **Profile → Diagnostics** on iPhone or **Account → Diagnostics** on iPad.
2. In build 50, use the copy icon in the top-right corner to copy every error retained from the last 24 hours.
3. Choose **Report a problem**, optionally describe what happened, and tap the checkmark. Confirm **Yes, Send** to submit. The report automatically includes your app information and up to 200 recent errors. Each diagnostic entry shows a timestamp, the app area and the type of failure.
4. Reports use a private GitHub inbox for authorized support staff. Live delivery requires a configured server credential. If sending is unavailable, you can still review and copy diagnostics on your device.
