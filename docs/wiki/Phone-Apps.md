# Phone apps

**Updated on** November 11, 2026 · **Updated by** Codex for Stați

Phones use the main Stați experience. Choose [iPhone](https://github.com/Hapi-Products/stati/wiki/iPhone) or [Android phones](https://github.com/Hapi-Products/stati/wiki/Android-Phones) for the exact screens and features.

1. Use the invite or receiver code provided by your church.
2. Confirm your account and the destination computer. A QR may open an enrollment, approval, sign-in, or file-submission screen depending on the computer’s current action.
3. Before sending, check the computer name and file title.
4. Confirm the status. A queued item may still need an operator to save it.

If a code opens the wrong screen, return to the computer and check which action generated it. [Connect a computer](https://github.com/Hapi-Products/stati/wiki/Connect-a-Computer)
