# Stați for Mac

**Updated on** November 11, 2026 · **Updated by** Codex for Stați

Mac development previews use the shared desktop workspace, including the queue and available station controls. The project currently prepares local previews for Apple silicon. Use the release notes for the particular build you received.

## Open a preview

1. Confirm the preview came from your project maintainer and check the version.
2. Open Stați and complete pairing or choose your named profile.
3. Use **Queue** to review received material. Open Settings from the app menu to find computer and workspace preferences.
4. Check that the connected computer, account, and service match the ones you intend to use.

The local previews are ad-hoc signed. If macOS refuses to open a build, record the exact message and ask your maintainer for the correct installer. Microsoft PowerPoint automation is a Windows feature.

## If sign-in stalls

Refresh the sign-in screen, choose your profile again, and confirm the matching account on your phone if prompted. If a Keychain prompt keeps returning, record the exact text and the build number. That helps identify whether the issue concerns the app identity or its stored credentials.
