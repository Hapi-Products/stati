# Stați updates

**Updated on** November 12, 2026 · **Updated by** Codex for Stați

Published downloads are listed at [Stați releases](https://github.com/markusciani/stati-releases/releases). This page also documents development builds so you can tell when the instructions require a preview.

| Build or platform | Change and status |
| --- | --- |
| iPhone and iPad development build 56 | On iPad, keeps the idle service dot gray, adds a Link Notes icon to the song toolbar, and expands the in-app wiki guides. See [Song reader help](https://github.com/Hapi-Products/stati/wiki/Song-Reader#get-help-in-portrait-or-landscape). |
| iPhone and iPad development build 55 | Keeps the live service indicator’s green, red, and gray colors in the iPad toolbar. |
| iPad development build 53 | Adds a live worship reader for the active service and named group. The server access checks and simulated PDF page following passed. |
| iPhone and iPad development build 52 | Uses the selected accent in guide and preview controls, puts Focus at the bottom right, matches the PDF reader to the app theme, and asks before enabling Developer Mode. |
| iPhone and iPad development build 51 | Wiki guide controls and highlights use neutral colors by default and follow the selected Stați accent. |
| iPhone and iPad development build 50 | Adds opt-in Developer Mode for Stați shortcuts, icons in Account and Features, a 24-hour diagnostic log, and an in-app private report form. Installed and checked on a physical iPad. Live report delivery requires server setup. |
| iPhone and iPad development build 49 | Opens the service picker from Siri or the song menu. Drag a catalog song into the running order and save. Diagnostics reports Siri AI preview requirements. |
| Windows preview 46 | Adds a song library folder picker for folders such as Lyrics synced by Google Drive for desktop. |
| Windows preview 44 | Adds signed-in Tasks and Groups pages with task notes, member lists, and shared file listings. |
| iPhone and iPad development build 48 | Stazi Beta uses a fixed blue icon and accent. Removes the beta switch and iPad Recents search. Combines the reader controls in one glass bar and improves tap and drag on the slide text slider. |
| iPhone and iPad development build 46 | Moves Siri and reader preferences into Stați. Adds in-app diagnostics and GitHub report drafts, a clear-history action in iPad Recents, and group switching inside the Groups tab. Group managers can remove a worship group while retaining its records. |
| iPhone and iPad development build 45 | Adds pop-up guides beside iPad controls, a two-column Features layout, smoother text resizing, and direct service toolbar actions. What’s New includes the recent builds again. |
| iPhone and iPad development build 43 | Adds the iPad Features page in Apple Settings, a slide text size slider and a Clicker switch. Registers the optional Siri AI library search action for compatible devices. Installed and launched on an iPad running iPadOS 27.3. The search action was tested with sample songs in the simulator. |
| iPhone and iPad development build 42 | Adds built-in Worship settings and song reader help on iPad. |
| iPhone and iPad development build 41 | Restores Worship controls in the app and mirrors them to Apple Settings on iPad. |
| iPhone and iPad development build 40 | Removes Hymnary. Send remains on iPhone and the iPad Songs toolbar focuses on the library. |
| iPhone and iPad development build 39 | Sets the minimum OS to iOS or iPadOS 26.3. |
| Windows | Use the releases page for downloadable versions. See the [Windows guide](https://github.com/Hapi-Products/stati/wiki/Windows) for the service and ProPresenter workflows. |
| macOS | Local Apple silicon previews are under development. |
| Android | The Android package uses the shared web experience. Dedicated tablet editions are planned. |
