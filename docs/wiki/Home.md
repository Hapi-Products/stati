# Stați user guide

**Updated on** November 11, 2026 · **Updated by** Codex for Stați

Stați helps church teams connect to their presentation computer, organize services, find songs, and share material. Start with the guide for the device you use. Each platform page explains what is available and which features require a preview build.

| Device | Guide |
| --- | --- |
| Windows computer | [Stați for Windows](https://github.com/Hapi-Products/stati/wiki/Windows) |
| Mac | [Stați for Mac](https://github.com/Hapi-Products/stati/wiki/macOS) |
| iPhone | [Stați for iPhone](https://github.com/Hapi-Products/stati/wiki/iPhone) |
| iPad | [Stați Worship for iPad](https://github.com/Hapi-Products/stati/wiki/iPadOS) |
| Android phone | [Stați for Android phones](https://github.com/Hapi-Products/stati/wiki/Android-Phones) |
| Android tablet | [Stați for Android tablets](https://github.com/Hapi-Products/stati/wiki/Android-Tablets) |
| Browser | [Stați on the web](https://github.com/Hapi-Products/stati/wiki/Web) |

## Common tasks

- [Phone apps](https://github.com/Hapi-Products/stati/wiki/Phone-Apps) covers sign-in, connecting to a church computer, and submitting a file.
- [Tablet apps](https://github.com/Hapi-Products/stati/wiki/Tablet-Apps) covers worship tools and the availability of tablet editions.
- [Connect a computer](https://github.com/Hapi-Products/stati/wiki/Connect-a-Computer) walks through pairing and approval.
- [Troubleshooting](https://github.com/Hapi-Products/stati/wiki/Troubleshooting) helps with sign-in, slow services, pending uploads, and missing songs.
- [Updates](https://github.com/Hapi-Products/stati/wiki/Updates) records which builds each guide describes.

Get distributed installers from [Stați releases](https://github.com/markusciani/stati-releases/releases). The source repository and development previews may show newer work than those installers.
