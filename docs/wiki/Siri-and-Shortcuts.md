# Siri and Shortcuts on iPhone and iPad

**Updated on** November 11, 2026 · **Updated by** Codex for Stați

## Run a shortcut

1. Sign in to Stați. On iPhone, open **Profile → Features**. On iPad, open **Account → Features**.
2. Turn on **Siri Shortcuts**. Open **Shortcuts** and look for the Stați app to run its actions directly.
3. Try the phrases below. If Siri hears the name differently, run the action in Shortcuts or rename a personal shortcut to a phrase that Siri recognizes.

| Try saying | Stați action |
| --- | --- |
| “Find a song in Stați” | Prompts for the title or part of a lyric and opens library results. |
| “Open a song in Stați” | Runs the same search. Select the version yourself from the results. |
| “Browse songs in Stați” or “Show all songs in Stați” | Opens the alphabetical song library. |
| “Show services in Stați” | Opens Services. |
| “Show recent songs in Stați” | Opens Recents. |

Use the app name shown in Shortcuts when speaking a phrase. The phrases above are registered in English. You can type a Romanian title or lyric in the shortcut or in Stați’s song search if Siri mishears it. A search returns songs available to your signed-in account.

## Try Siri AI search

On a compatible device, enable Siri AI in Apple Settings and turn on **Siri AI Song Search** in Stați’s Features. Try “Search Stați for Amazing Grace.” This is a preview of Apple’s in-app search action. It searches the Stați library and lets you choose a result. Siri recognition and whether it routes a spoken request to Stați depend on Apple’s supported devices, languages, and settings. The regular shortcuts above are available separately from Siri AI.
