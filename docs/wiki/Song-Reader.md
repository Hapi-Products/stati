# Song reader on iPad

**Updated on** November 13, 2026 · **Updated by** Codex for Stați

## Read a song

1. Open **Browse** and select a result, or open **Service** and choose the song in the running order.
2. Use the arrows in the glass page control to move one page at a time. The page counter in the middle opens thumbnails. When there are multiple pages, you can also tap the left or right edge of the reader.
3. Open the page previews from the page counter. Select a thumbnail to jump to that slide.
4. Tap the **music note list** at the top left to jump to a different song. The selector can show Recents or the active service. The **X** at the far left closes the reader. In build 61, each control has its own glass button.

## Link a shared file

1. Open the song on iPad. If your role allows linking notes, open **Notes → Link a file** in development build 65. In earlier builds, use **Reader options (•••) → Link shared notes**.
2. Select a file you shared or a file you manage as an administrator. Tap **Load older files** if the file is on another page.
3. Open **Notes** to view the linked file. Repeat for any other files you want to attach to this song.

Linking leaves the original file in **Groups** and preserves its permissions. If you can manage the link, use **Notes → Unlink file** to remove it from the song.

## Read a linked PDF or image

On iPad in development build 64, open a linked PDF to swipe between pages or choose a page from the counter. Tap the half-filled circle to invert a PDF or image for reading. The eye icon opens the file in Quick Look for Markup or sharing.

## Get help in portrait or landscape

Tap **Help** (the question mark) in the song reader toolbar. The guide starts with the reading formats, then covers Song Selector, page previews when available, linking notes from Reader options, and Focus. If you’re following a live leader, the guide explains why manual song and page controls are unavailable.

Use the arrow buttons to go forward or back. A step points to its control when possible; overview steps and steps without an on-screen anchor open in the middle. Tap the **book** icon on any step to open this page.

## Set up the reader

In **Account → Features**, choose the reading format, size, and song selector. Open **PDF Layout** to choose the number of columns and page transition for the PDF reader.

Use the focus button in the lower right to hide or restore the reader controls. Text uses a larger reading size. The PDF reader follows the app’s light or dark appearance.
