# Connect a computer

**Updated on** November 21, 2026 · **Updated by** Codex for Stați

## Pair or request access

1. Ask the church operator to open Stați on the computer you need.
2. Choose the relevant action on the computer. Use the pairing or access QR for connecting an account and the receiver QR when submitting a file.
3. On your phone, scan the code using the app’s camera action when available or your device camera.
4. Confirm the computer name. Sign in to your existing account if prompted.
5. If the request needs approval, ask the operator to review it. Wait for the computer to appear in your list.

## Connect Ilumin8

Use Ilumin8 on the church’s Mac or Windows presentation computer. In Ilumin8, open **Settings → Integrations → Stați account**, then select **Connect Stați**. Open the pairing page or scan its QR code from **Add computer** in Stați. Sign in with the account that should own this connection and confirm the computer name.

Select an existing approved song library in Ilumin8 to import its lyrics. Turn on **Publish songs to Stați** to make your local lyrics available to approved worship members on phones and tablets. You can use Ilumin8 for presentations with the account disconnected.

## Use the Ilumin8 clicker

On Ilumin8, open **Settings → Controls**, start the local phone connection, and create a **Phone clicker** QR code. Scan it in an updated Stați web or handheld scanner. Review the computer address and open the clicker. Ask the operator to approve the phone, then use the arrows to change live slides. Both devices must be on the same network and the phone must trust the Ilumin8 certificate.

A profile-enabled QR requires a signed-in Stați account and the updated scanner. Check the computer address and choose **Open with Stați** to share your first name and profile photo. The operator reviews the verified name and approves the phone or tablet. With the operator’s permission, you can add songs to the active schedule, advance slides, or set the stage timer. The operator can restrict this service to viewing or block access for this service.

For devices without a Stați account or an updated scanner, the operator can create a guest QR. Open that code with your device camera. Guest submissions do not carry a Stați profile credit. The new profile workflow is still awaiting physical-device verification.

## Pick your usual computer

In the app, open your profile or account and select the default computer. You can switch destinations before sending. A computer may be connected to your account yet offline at the time you try to use it.

If a code expires, generate a new one at the source. If the computer is missing after approval, refresh the list with the same account that requested access.
